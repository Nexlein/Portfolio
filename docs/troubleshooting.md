# Troubleshooting

| Symptom                                                                                                                  | Cause                                                                                                                      | Fix                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Every commit fails with `sh: 0: Illegal option --`                                                                       | `husky` was run with an argument (`npx husky --version`): husky takes it as the hooks folder and rewrites `core.hooksPath` | Run `npx husky` with no argument, delete the stray folder it created. Never pass arguments to `husky`.                                                                                                                                                                                                               |
| A commit in a new clone or worktree runs no hooks                                                                        | `core.hooksPath` is `.husky/_`, which `npm ci` creates (`prepare` script)                                                  | `npm ci` in that folder, then commit again: lint-staged should print its tasks.                                                                                                                                                                                                                                      |
| Windows: hooks print "gitleaks not found" or "actionlint: not found"                                                     | Git runs hooks outside your shell, so mise's tools are not on its `PATH`                                                   | Add `%LOCALAPPDATA%\mise\shims` to your user `Path` ([mise docs](https://mise.jdx.dev/shell-setup.html#windows)). Without it the commit still goes through. CI runs the other checks, but the gitleaks scan and the commit-msg rule run only in the hooks (GitHub push protection still blocks known token formats). |
| `npm run media:video` fails on Windows                                                                                   | it is a bash script using GNU `mktemp`                                                                                     | Run it from Git Bash.                                                                                                                                                                                                                                                                                                |
| `npm run check` fails at `npm audit` offline                                                                             | the audit needs the npm registry                                                                                           | Run it online.                                                                                                                                                                                                                                                                                                       |
| `CI=1 npx playwright test` fails at startup                                                                              | port 4173 or 4174 is taken (`npm run preview`, `npm run cv:pdf`); `CI=1` also turns on `forbidOnly` and the CI reporter    | Stop the other server. Prefer letting CI run Firefox and WebKit.                                                                                                                                                                                                                                                     |
| A Firefox or WebKit failure you cannot reproduce                                                                         | those engines run in CI only                                                                                               | Read the trace in the `playwright-report` artifact of the failed run.                                                                                                                                                                                                                                                |
| VSCodium's GitHub Actions extension flags `.github/actions/setup/action.yml` ("Required property is missing: on / jobs") | it validates the file as a workflow when it is opened from a diff or source-control view (`git:` URI)                      | Nothing to fix: open the file itself, and the errors go away.                                                                                                                                                                                                                                                        |
| A Vercel preview link asks for a login                                                                                   | previews are behind Vercel Authentication                                                                                  | Sign in to Vercel, or check the production site after the release.                                                                                                                                                                                                                                                   |
| Uptime or weekly rebuild stopped running                                                                                 | GitHub turns scheduled workflows off after 60 days without activity; runs also start hours late                            | Turn them back on in the Actions tab ([operations.md](operations.md#scheduled-jobs)).                                                                                                                                                                                                                                |
| Weekly rebuild fails with "VERCEL_DEPLOY_HOOK is not set"                                                                | the repo secret is missing                                                                                                 | Create a Deploy Hook for `main` in Vercel, store its URL as `VERCEL_DEPLOY_HOOK` ([operations.md](operations.md#vercel)).                                                                                                                                                                                            |
| A Dependabot PR targets `main`                                                                                           | security updates always open against the default branch                                                                    | `gh pr edit <n> --base dev`                                                                                                                                                                                                                                                                                          |
| Renovate opens nothing, or its log shows `config-validation`                                                             | it reads `renovate.json` from `main`, and one invalid rule stops it                                                        | Fix the file in a PR (the `Renovate config` job validates it), then release.                                                                                                                                                                                                                                         |
| A PR into `main` waits for a check that never comes                                                                      | a job was renamed, and the branch rule still expects the old `name:`                                                       | Update the required checks (Settings → Branches), or restore the name.                                                                                                                                                                                                                                               |
| `git pull` in a clone from before 2026-10-07 shows unrelated history                                                     | the history was rewritten that day (old media removed)                                                                     | Clone again.                                                                                                                                                                                                                                                                                                         |
