Linear Perceptron (Supervised)

Supervised Learning means we provide the algorithm with labelled data (we tell it exactly which points are Red and which are Blue). The algorithm learns by making predictions, checking its answer against our labels, and adjusting its weights when it makes a mistake to draw a dividing line between the two known classes.

How it learns:

Output: y = step(w₁x₁ + w₂x₂ + b)
Update: wᵢ = wᵢ + η(target - y)xᵢ
